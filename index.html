Fitur Spesialis MIKASAHUNTER

Dirancang khusus untuk menghadirkan fungsionalitas pentesting tingkat lanjut pada perangkat mobile Anda tanpa mengorbankan stabilitas.

Monitor Mode & Injection

Dukungan penuh untuk dongle Wi-Fi eksternal (Atheros, Ralink, Realtek) langsung colok via OTG dengan kemampuan packet injection.

BadUSB / HID Attack

Ubah smartphone Anda menjadi keyboard/mouse virtual otomatis untuk melancarkan serangan HID injection (Rubber Ducky style).

Overclock & Battery Saver

CPU/GPU governor yang telah dikalibrasi untuk performa ekstra tinggi saat dibutuhkan, serta mode hemat daya instan saat idle.

Petunjuk Instalasi

Pastikan Anda telah melakukan backup data sebelum memulai proses flashing.

01

Masuk ke Custom Recovery

Matikan ponsel Anda, lalu masuk ke mode TWRP, OrangeFox, atau PBRP recovery dengan menekan tombol Power + Volume Up.

02

Flash Kernel .zip

Cari file zip kernel MIKASAHUNTER yang telah di-download, pilih install/flash file tersebut (menggunakan toolkit AnyKernel3 bawaan).

03

Reboot & Verifikasi

Reboot system. Buka aplikasi NetHunter App atau terminal emulator lalu jalankan perintah berikut untuk memastikan driver aktif:

$ uname -a
# Output harus menunjukkan branding 'mikasahunter'
